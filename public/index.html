Authentication & Task API Specifications

POST /api/auth/register

Registers a new user with bcrypt password hashing (10 salt rounds) and returns JWT token.

POST /api/auth/login

Validates credentials with bcrypt.compare and returns signed JSON Web Token.

GET /api/auth/me

Protected route: Verifies JWT token and returns authenticated user profile.

GET /api/tasks

Retrieves tasks with search (regex) and pagination (?page=&limit=).

POST /api/tasks

Protected (JWT): Creates task in MongoDB. Validates fields and sets createdBy.

PUT /api/tasks/:id

Protected (JWT): Updates task fields with Mongoose runValidators: true.

DELETE /api/tasks/:id

Protected (JWT): Deletes task document from MongoDB by ID.

GET /api/health

Service probe returning server uptime and MongoDB connection state.
